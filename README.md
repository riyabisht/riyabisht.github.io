# Portfolio Site

This is the source code for my portfolio website.

## Projects

Project content lives in `_data/projects.yml`. Add an item to that list to show it on the projects page. Set `featured: true`, `summary`, and a supported `visual` value (`digit` or `recipe`) to also show it on the homepage. The `id` value is used for project-page anchor links.

## Blog

The site is the canonical home for blog posts. Add a Markdown file to `_posts/` named `YYYY-MM-DD-post-title.md`, with at least a `title` in its YAML front matter; posts use the shared `post` layout and appear automatically at `/blog/`. For example:

```yaml
---
title: A post title
---
```

Medium can be used to cross-post writing when useful, but posts here remain on the portfolio site and no Medium integration is required.
