    <p class="project-type">Machine learning <span>01</span></p>
    <h2>Handwritten digit recognition</h2>
    <p>Trained a convolutional neural network on the MNIST dataset to identify handwritten digits, then built a web app to interact with the model.</p>
    <p class="project-outcome">The model reached 98.63% accuracy on the MNIST dataset.</p>
    <ul class="tech-list" aria-label="Technologies used">
      <li>Python</li><li>Pandas</li><li>TensorFlow</li><li>Keras</li><li>NumPy</li><li>Matplotlib</li>
